339 change
- Reuse prepared bundled chess sound sources with ReleaseMode.stop rather than
  destroying and recreating MediaPlayer sources after every effect.
- Set board audio context/volume once per prepared effect, coalesce concurrent
  requests for the same effect. Keep audio focus disabled for coach compatibility.
- Failed preparation can retry. Disposal clears references so sounds can restart.
- Keeps 338 byte-source mitigation, all architectures, assets and ad formats.
- Retains at most the fixed collection of lazily-used sound players; does not
  preload all audio or change SDK dependencies. Production memory/performance
  improvement needs device/field validation; this is a mitigation, not proof.
