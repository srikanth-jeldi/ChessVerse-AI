Release 1.3.44 (311): Set Up Board

Implemented
- Analysis dashboard: Set Up Board entry.
- Editor: independent White/Black to move and human playing colour.
- Analyse Position opens the existing authenticated Stockfish candidate API.
- Best/alternative moves, evaluation from White's perspective, legal line
  previews, move navigation, original FEN, bounded timeout and retry states.
- Play against AI retains the exact custom FEN and chosen side to move.
- Turn/clock/hint/AI scheduling, undo and FEN generation respect a Black start.
- Custom initial castling rights are respected instead of reconstructed from
  king/rook placement. New setups begin without castling/en passant rights.
- Invalid non-moving king checks are rejected before either action.
- Chess board coordinates remain left-to-right in RTL interfaces.
- 34 catalogs contain 962 labels each; brand tokens remain unchanged.
