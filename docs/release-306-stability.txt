Release 1.3.39 (306) - stability changes, 19 October 2026

HSDP investigation
Crashlytics reports IllegalStateException: targetPackageName is null in
HsdpShimActivity.zzd, including HSDP 2.1.0. The upstream release notes now
document a HsdpShimActivity crash fix in 2.2.0:
https://developer.android.com/reference/com/google/android/play/core/release-notes-hsdp

Compared the published Google Maven 2.1.0 and 2.2.0 class bytecode. 2.1.0
throws when target_package_name is absent. 2.2.0 validates intent extras in
onCreate, calls finish on invalid input, and skips onAttachedToWindow while
finishing. Its service-show path also validates required extras. Upgraded
the explicit dependency to 2.2.0; Gradle releaseRuntimeClasspath confirms
the ads SDK's transitive 2.0.1 dependency resolves to 2.2.0.
No ad units or device models are disabled by this change.

Network handling
An http.ClientException during the periodic health probe now produces a
non-blocking offline banner instead of the full server-unavailable overlay.
This covers the reported unreachable-network, DNS and connection-abort
transport errors. Existing connectivity events, 30-second probes and Retry
restore online state after recovery. HTTP 503 still reports server failure.
Expected transport failures retain a diagnostic breadcrumb instead of being
recorded as application exception events. Unexpected errors and TLS errors
retain error reporting; this is not a blanket suppression of diagnostics.

Also includes the previously tested save-conflict dialog lifecycle fix and
the pending club reward/post-match trial changes already present in source.
The release inherits the production configuration from 305, including the
10% post-match rewarded-interstitial trial. No Play rollout is performed.

Verification
27 focused tests passed with the production trial flag enabled: offline and
recovery, server response distinction, network UI, save conflict and resume,
hint/analysis disposal, ad initialization and rewarded-interstitial flow.
The initial trial run without its required flag failed; rerun with the
release flag passed. Full Flutter analysis: no issues found.
Release packaging checks are in artifacts/release-1.3.39-306/release-report.json.

Limitations
No claim of zero future crashes or ANRs. Tecno native WebView/linker ANR is
separate from HSDP and is not proven resolved. HSDP evidence here is official
release notes, bytecode comparison and packaged dependency verification;
this is not a physical-device recreation of the original user's session.
