Included features
- Daily puzzle weekly coin cycle: 10/15/20/25/30/35/40; missed-day reset;
  completion Done returns Home. Server validates current catalogue solution
  before awarding daily coins and uses a date-scoped idempotency key.
- Daily practice plan based on saved history and Mistake Bank; guided opening
  practice; supported public Chess.com game URL import. The plan is derived
  from app data, not a claim that a generative model has analysed every game.
- Achievement badge requirements, progress and earned status. Existing owned
  badges remain owned; decorative badges promise no rating or coin advantage.
- Tournament preview pairings use registered players only. Existing preview
  slots remain stable as entrants join/leave; matches are created at start.
  Past events and verified round scores can be revisited.
- Mobile feature-activity instrumentation for the existing daily usage report.
