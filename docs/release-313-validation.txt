Release 1.3.46 (313): Android download size budget

Target: compressed device download <= 25,000,000 bytes for every supported ABI.
This is not the AAB upload size or installed storage footprint.

x86_64: 33,254,321 / 33,529,056

Changes
- Optimised 193 WebP assets; 7,765,436 source bytes saved.
- Gameplay pieces keep their original pixel dimensions and alpha channels.
- Trophy previews capped at 512px, badges 384px, collection previews 640px,
  backgrounds 1280px longest edge, and matchmaking preview 640px,
  preserving aspect ratios.
- All asset paths retained. No native library, ABI, font, language or audio
  removed. No dependency changes or game/network/ads logic changes.
- Dart debug information separated into archived symbol files for diagnosis.
- Version bumped from 1.3.45+312 to 1.3.46+313.

Validation

  localization catalogs, and decoding every bundled WebP with Flutter.
- Visual comparison of original/optimised board background and premium
  knight showed preserved recognisability at the same gameplay resolution.
- Earlier build-311/312 physical tests cover unchanged game/setup logic;
  this does not mean all devices or every future ANR/crash is ruled out.
