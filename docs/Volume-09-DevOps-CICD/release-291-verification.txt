Private Mistake Bank backup
PUT /api/v1/progress/mistakes authenticates the player from the bearer session.
V85 adds player_mistake_backup, with account deletion cascading to its rows.
The latest 100 mistakes include the original game context, FEN, played/best
move, principal variation, explanation, and practice review state (including
assisted completions, attempts, successes, review stage and next-review date).
Merges are serialized per account and use updatedAt per mistake. Empty-device
uploads restore the existing backup; they do not replace it with an empty bank.
Guests are excluded. Academy sharing permissions are unchanged.
The app syncs after login, on resume, after saved-game/review changes, and on
opening the bank. Network failures retain local data and retry. A late response
for a previous login cannot be applied to the active account. Existing puzzle,
daily challenge and completed-lesson progress continue using the progress API.
Install the update and allow an online sync BEFORE uninstalling the old app.
Data that was never uploaded and was already erased cannot be recovered by
this new backup. Practice counters use newest-record conflict resolution,
not additive aggregation of simultaneous offline practice on multiple devices.
