ChessVerseAI 1.3.71 (338) - release verification, 4 November 2026

Included changes
- Gold/navy design updates, Collection wallet and tabs, removed decorative badge above Collection heading.
- Home shortcut grid uses three columns; daily practice cards and screen spacing updated.
- Muting automatic coach audio keeps the written AI Coach content available.
- Android board sounds use BytesSource rather than the UrlSource file-provider path.
- Collection header king and miniature fallback pieces decode at bounded sizes.
  Board and badge catalogue artwork was already resized; it retains its existing size.
- ARM32, ARM64 and x86_64 remain supported. No native library removal for size savings.

Validation scope
- Targeted automated suite: 2,294 tests passed, including all-language screen layouts,
  loaded/error/dialog/keyboard interaction matrix, Collection, enlarged text, voice layout,
  bottom spacing, audio and startup regressions.
- F41 physical-device English Collection smoke test: header icon removal, wallet,
  Boards / 3D pieces / Badges tabs, and scrolling to the last badge checked.
  No overflow exceptions found in the inspected test-app log buffer.
- All screens in all 34 languages have NOT been manually verified on a physical device.
- Full regression, static analysis and artifact verification results are recorded below
  after completion.

Stability and performance limitations
- The identified Play vitals audio ANR cluster was observed on old builds 249/311.
  The BytesSource change avoids that specific main-thread ContentResolver/Binder path;
  it is a mitigation, not evidence that every ANR is resolved.
- Existing historical events remain in Play/Firebase reporting windows. Validate the
  new version separately after rollout; do not close issues only to clear the list.
- F41 DEBUG activity cold launch: 8,093 ms (am start -W). This is not release startup
  timing, not time-to-interactive, and not a valid comparison to Play startup metrics.
- Debug test-app PSS after UI exploration: approximately 701 MiB. Debug/JIT overhead
  makes this unsuitable as a production memory benchmark.
- Production cold/warm startup and frame-time improvement are not yet confirmed.
- This release does not include the unfinished replacement of every premium chess piece.

Completed regression results
- Full non-golden suite: 3,813 passed, 3 skipped, 5 failures initially.
- Four stale collapse expectations were updated to match audio-only mute behavior.
- Post-game layout test explicitly disables sound in stored preferences so a native
  audio mock cannot leave a pending prepare timer during a visual-only test.
- All affected files plus Collection localization rerun: 153 passed, zero failures.
- flutter analyze --no-pub: No issues found.
- Release builds after tests must regenerate platform tooling: omit --no-pub.
  Flutter 3.47.4 otherwise preserves the debug integration_test registration while
  Gradle correctly excludes that dev-only plugin from release dependencies.
