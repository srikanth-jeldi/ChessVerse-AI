Translation quality and blocker
- Public translation service returned HTTP 429 after the initial catalogs.
- An MIT-licensed local model was evaluated, but its new translations were
  rejected for obvious semantic errors. Its additions were removed from the
  shipped assets and cache. The local generator was removed.
- Telugu's remaining 392 phrases were written separately; chess-context
  overrides correct labels such as TRAIN. Other retained machine translations
  still need native-language editorial review.
- A working translation service/configuration is needed to complete the
  remaining 32 catalogs. Never publish this as "all 34 languages complete."

New feature questions — findings, not new feature implementation
- MistakeReview already implements 1, 3, 7, 14 and 30-day spaced repetition.
  Early replay does not advance it; an incorrect retry schedules tomorrow.
  This does not establish automatic reminders or generated related puzzles.
- Existing CloudNarrationService uses the backend speech endpoint, audio
  caching and device-TTS fallback. Backend SpeechSynthesisService uses Azure
  Neural voices; Telugu is te-IN-ShrutiNeural. Live provider availability was
  not checked.
- ElevenLabs/Google TTS integration and Serious/Friendly/Fun coach choices
  are feasible proposals, not implemented changes in build 307.
- Stockfish-validated related puzzles and automatic SRS reminders remain
  separate feature work.
