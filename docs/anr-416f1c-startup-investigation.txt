Source change
- The project targets Android SDK 36. Android 15+ enforces edge-to-edge for
  this target, so skip the redundant post-first-frame SystemChrome window
  reconfiguration on API 35+.
- Preserve explicit edge-to-edge styling on older Android and other native
  platforms.
- Obtain only Build.VERSION.SDK_INT on the existing background method channel;
  no WebView lookup, disk access or Binder query in this new method.
- Unknown, missing or timed-out API query leaves the window unchanged; no retry.
- This is a startup-risk mitigation, NOT a verified fix for the native ANR.
