Release 1.3.47 (314): Guest conversion and safe account merge

Behaviour
- Two persistent guest uses per feature: review/position analysis share one
  counter; Mistake Bank has a separate counter. Third access prompts Google
  sign-in. Empty Mistake Bank and failed/empty position analysis do not count.
- No startup sign-in prompt. Prompt is dismissible; signed-in accounts bypass
  the trial regardless of their authentication provider.
- New Google identity keeps the same server player and wallet. Local archive
  identity is upgraded without deleting guest progress.
- Existing Google-linked account receives missing server computer game IDs
  and private Mistake Bank records. Local saved games and SRS practice records
  are merged, with a durable, target-bound recovery snapshot.
- Existing target wallet, reward ledger, purchases, streak and unfinished game
  are not copied from the guest. A guest archive cannot be claimed by a second
  target account. Same-account retries deduplicate by game/mistake ID.
- Google token verification and a valid source guest session are required.
- Trial counters are stored on the device, not an anti-abuse server quota.
- New copy bundled in all 34 languages; ChessVerseAI name remains unchanged.
- Three onboarding wide previews reduced to 1024px longest edge to retain
  download-size headroom. Gameplay pieces/native dependencies unchanged.
