Changes since 325
- Daily challenge records retain their custom initial position. Regression
  coverage checks archive JSON round trips and every review position for
  the rotating daily puzzle catalogue.
- Legacy daily records missing a custom initial position, or incorrectly
  using the standard opening army, are excluded from saved history on load,
  insertion and cloud merge. Their original positions cannot be recovered
  reliably. Daily streak, completion and wallet data are not changed.
- Puzzle Academy practice remains excluded from My Games.
- Cloud computer-game history now retains initialFen when mapping records.
- Learner Set Up Board enforces each side's standard inventory: one king,
  one queen, two rooks/bishops/knights and eight pawns. Removing a piece
  restores its available count. Pawns cannot be placed on ranks 1 or 8.
- Black king width adjusted in the setup board and palette.
- Existing release 325 features are retained.
